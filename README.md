# probabilistic-market-risk-modeling
# Сравнительный анализ вероятностных моделей динамики цен акций для оценки VaR

Исследовательский проект магистерской диссертации. Основная задача — сравнить качество однодневных оценок Value at Risk (VaR) для отдельных акций и установить, когда учёт тяжёлых хвостов и смены рыночных режимов оправдывает усложнение модели. Expected Shortfall (ES) рассматривается как дополнительное направление исследования.

**Текущий статус:** вычислительный прототип; итоговые экспериментальные выводы по новому протоколу ещё не получены. README сверен с локальными исходниками 18 октября 2026 года. Сохранённые выводы ноутбуков относятся к прежней методике.

## Постановка исследования

**Цель:** разработать воспроизводимую процедуру сравнительной оценки вероятностных моделей по точности, калибровке и вычислительной стоимости прогнозов VaR дневных доходностей акций.

**Исследовательский вопрос:** улучшают ли тяжёлые хвосты распределения и марковское переключение режимов оценку рыночного риска по сравнению с простой нормальной моделью и историческим методом?

- **Объект:** динамика цен и дневных доходностей отдельных акций.
- **Предмет:** влияние вероятностной модели доходностей на качество оценки VaR.
- **Ожидаемый научный вклад:** эмпирическая оценка вклада тяжёлых хвостов, смеси распределений и устойчивости режимов во времени при общем протоколе сравнения. Создание нового семейства моделей не заявляется.
- **Практическая значимость:** обоснованный выбор модели оценки риска с учётом качества прогнозов, устойчивости оценивания и затрат времени.

## Модели

| Модель | Что позволяет проверить | Состояние реализации |
|---|---|---|
| Normal | Базовое нормальное распределение доходностей | `GBM('normal')` в `models/gbm.py` |
| Student | Вклад тяжёлых хвостов | `GBM('student')` в `models/gbm.py` |
| GMM | Вклад двухкомпонентной нормальной смеси | `GMM_2` в `models/gmm.py` |
| MSM | Вклад зависимости скрытых режимов во времени | `MSM_2` в `models/msm.py`, два марковских режима;  |
| Heston | Вклад стохастической волатильности | `Heston` в `models/heston.py` |

Название класса `GBM` сохранено из прототипа. Его текущая реализация подбирает распределение логарифмических доходностей; наличие класса само по себе не означает реализацию непрерывной ценовой траектории для каждого варианта распределения.

## Данные и подготовка

В `data/` находятся локальные CSV. 

| Тикер | Строк цен в локальном CSV | Первая дата в файле | Последняя дата в файле |
|---|---:|---|---|
| GAZP | 2967 | 2014-06-09 | 2025-12-26 |
| SBER | 3590 | 2011-12-15 | 2025-12-26 |
| GMKN | 2963 | 2014-06-09 | 2025-12-26 |
| RTKM | 3581 | 2011-12-15 | 2025-12-26 |
| MGNT | 3590 | 2011-12-15 | 2025-12-26 |

Таблица описывает файлы на 18 октября 2026 года, до фильтрации и ограничения длины загрузчиком. Она не подтверждает полноту торгового календаря или качество цен. Все пять файлов имеют заголовок:

```csv
Date,Open,High,Low,Close,Adj Close,Volume
```

Текущая функция `get_data(ticker, data_dir='data')`:

1. Читает `<data_dir>/<ticker>.csv`, принимая первый столбец за индекс дат.
2. Использует **`Close`**, хотя в CSV также есть `Adj Close`.
3. Рассчитывает `r_t = log(Close_t / Close_(t-1))`.
4. Возвращает массив последних `252 * 11 + 1 = 2773` доходностей без дат.

Загрузчик не скачивает данные. Для запуска нужны соответствующие CSV в `data/` или явно заданный `data_dir`; относительный путь по умолчанию отсчитывается от текущей рабочей папки. Ноутбуки следует запускать из корня проекта.

## Методика сравнения

**Это целевой метод. Текущая реализация сильно упрощена и слабо информативна на тестах**

```text
Прошлые доходности → оценивание параметров → прогноз VaR следующего дня
                                               ↓
Следующий день → фактическая доходность → исключение / функция потерь
                                               ↓
                           обновление состояния → следующий прогноз
```

- Горизонт — **один торговый день**; переоценка параметров — каждые **21 наблюдение**.
- Для отладки предусмотрено скользящее окно **504 наблюдения**; кандидаты для последующего выбора — **252, 504 и 756**.
- Предложено разделение примерно 11-летней истории: 3 года начальной истории, 3 года последовательной валидации, 5 лет итоговой ретроспективной оценки. Фактические границы предстоит зафиксировать по датам.
- Настройки выбираются только на раннем участке по заранее выбранной функции потерь. На итоговом периоде правила больше не подбираются по результатам.
- Прогноз сохраняется **до** наблюдения прогнозируемой доходности. Режим MSM обновляется после завершения дня. Обучающие окна могут перекрываться; целевая дата должна иметь один итоговый прогноз на сочетание модели и уровня риска.
- Калибровка VaR: частота исключений, тест Купика, тест независимости Christoffersen.
- Сравнительное качество: средняя quantile loss и парные различия на одинаковых датах;
- Практическая оценка: время обучения, доля сбоев и чувствительность к старту. Максимальный p-value не используется как критерий выбора лучшей модели.

ES — дополнительная задача: реализовать прогноз хвостового среднего, один верифицированный ES-бэктест и при необходимости совместную функцию потерь VaR–ES.
